# KevBot Chatbot

KevBot is a Java-based chatbot project developed using Apache NetBeans. The project includes a text-to-speech feature using the FreeTTS library and an interactive chatbot that can respond to user input.

## Features

- Interactive chatbot
- Asks for the user's name and provides a personalised welcome message
- Responds to different user inputs
- Text-to-Speech functionality
- Displays available FreeTTS voices
- Simple menu-based interface
- Input handling and validation

## How to Run

1. Open the project in Apache NetBeans.
2. Make sure the FreeTTS library is added to the project.
3. Open `SpeechToTextAndTextToSpeechChatbot.java`.
4. Run the project.
5. Select an option from the main menu.

## How to Use

When the program starts, the following menu is displayed:

1. Text to Speech
2. Chatbot
3. All Available Voices
4. Exit

Select option `2` to start KevBot.

KevBot asks for your name and then starts the conversation.

Example:

User: hello  
Bot: Hello! Nice to meet you.
